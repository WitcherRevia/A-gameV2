🌐 نشر اللعبة للعالم مجاناً برابط دائم

اللعبة مصممة كصفحة ويب متكاملة تعمل بدون خادم (HTML5 + WebRTC عبر PeerJS)، مما يعني أنه يمكنك استضافتها مجاناً 100% خلال دقيقة واحدة ليصبح لديك رابط دائم يدخل منه أي شخص في العالم:

1️⃣ الاستضافة المجانية عبر GitHub Pages:

1. قم بإنشاء مستودع جديد على GitHub وارفع ملفات اللعبة إليه.
2. ادخل إلى Settings ➔ Pages.
3. اختر فرع main واضغط Save.
4. ستحصل فوراً على رابط عالمي دائم مثل: https://username.github.io/game.

2️⃣ الاستضافة بنقرة واحدة عبر Vercel أو Netlify:

1. ادخل إلى Vercel أو Netlify مجاناً.
2. اسحب مجلد اللعبة (Drag and Drop) إلى لوحة التحكم.
3. سيعطيك الموقع رابطاً عالمياً سريعاً وفورياً مثل: https://my-game.vercel.app.

✨ ميزة الرابط الذكي التلقائي:

بمجرد فتح لعبتك عبر أي رابط استضافة، فإن الضغط على "مشاركة الرابط" في أي غرفة أونلاين سينسخ رابطاً مباشراً مثل https://domain.com/?room=ABCD. عندما يفتحه صديقك سيدخل الغرفة مباشرة بدون كتابة رمز!
